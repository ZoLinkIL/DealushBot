# דילוש (Dealush) – הסוכן האישי לדילים בטלגרם

בוט: [@DealushBot](https://t.me/DealushBot)

שולחים לבוט **צילום מסך** של דף מלון, **לינק** מכל אתר הזמנות (Booking, Agoda, Trip.com, Expedia, Hotels.com), או **שם מלון + תאריכים** – והוא מחזיר את אותו מלון באתרים אחרים.
מה עובד עכשיו ומה מחכה לחשבונות: ראו `ROADMAP.md`.

## הפעלה (בערך 15 דקות)

1. **יצירת הבוט:** ב-`@BotFather` שולחים `/newbot`, בוחרים שם ושם משתמש שמסתיים ב-`bot`, ושומרים את הטוקן.
   כדי שהבוט יעבוד גם בקבוצות: `/setprivacy` ← בוחרים את הבוט ← `Disable`.
2. **מפתח לקריאת צילומי מסך (מומלץ):** מפתח חינמי של Gemini ב-https://aistudio.google.com/apikey
   (או מפתח Claude ב-https://console.anthropic.com). בלי מפתח – הבוט מבקש לינק או טקסט.
3. **התקנה** (Python 3.10+):
   ```
   pip install -r requirements.txt
   ```
4. **הגדרות:** מעתיקים את `.env.example` ל-`.env` וממלאים: `TELEGRAM_TOKEN`, מפתח AI אחד, ו-`ADMIN_IDS`
   (המספר שלכם בטלגרם, מ-`@userinfobot` – פותח את `/stats`).
5. **הרצה:** `python bot.py`

## פקודות
- `/start` – הסבר קצר
- `/watches` – ההתראות שלי, עם ביטול
- `/stats` – נתונים למנהל בלבד: בדיקות, צילומי מסך, דיוק לפי דיווחי משתמשים

## מה יקרה כשהחשבונות יאושרו
- ממלאים את פרטי האפילייט ב-`.env` – כל הכפתורים הופכים לקישורי שותפים.
- מוסיפים ספק מחירים ב-`pricing.py` (ההוראות בקובץ) – ואז נדלקים אוטומטית:
  פסק דין 🟢 "נמצא זול יותר" / 🟡 "המחיר שלך טוב", התראות ירידת מחיר, ומעקב אחרי הזמנה.

## לבדוק ידנית לפני השקה
- שכפתורי Agoda ו-Trip.com נפתחים עם המלון והתאריכים הנכונים.
- צילום מסך מהאפליקציה של Booking ומהאתר – מזוהה נכון.
- שם המודל של Gemini/Claude ב-`.env` עדכני (שמות מודלים מתחלפים מדי פעם).

## קבצים
| קובץ | תפקיד |
|---|---|
| `bot.py` | הבוט: הודעות, כפתורים, התראות ברקע |
| `messages.py` | כל הטקסטים בעברית – לשינוי ניסוחים |
| `parsing.py` | זיהוי מלון, תאריכים ומחיר מלינק או טקסט |
| `vision.py` | קריאת צילומי מסך |
| `pricing.py` | מנוע ההשוואה: ספקי מחירים, סף, פסק דין |
| `links.py` | קישורי השוואה ואפילייט |
| `storage.py` | מסד נתונים (`bot.db`) – בלי פרטים מזהים חוץ ממזהה צ'אט להתראות |
| `config.py` | קריאת ההגדרות מ-`.env` |
| `test_*.py` | בדיקות: `python test_v2.py` |
